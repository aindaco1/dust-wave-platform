# Digest presentation

`@dustwave/digest-core` owns the characterized responsive HTML shell, cards, escaping and short display summaries shared by Opportunity Radar and GitHub Repo Scan. Consumers supply their own labels, grouping, approved links and content, and retain plain text, Markdown, storage, configuration, schedules and transport. It does not sanitize URL schemes; callers must supply reviewed URLs. It never sends email.

Pin the exact package version and Platform commit. Invalid input throws; consumers must validate report models first. Roll back a consumer independently by restoring its prior adapter and pin.
